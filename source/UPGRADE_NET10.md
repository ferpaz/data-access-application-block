# Plan de migración a .NET 10 — versión 10.0.0-rc1

## Objetivo y alcance

Migrar la solución existente `source\Data.sln` a `source\Data.slnx`, agregar un target nativo `net10.0`, conservar `netstandard2.0` y sustituir los targets de .NET Framework por `net48`. Si se confirma que Oracle no soporta `netstandard2.0`, aplicar la excepción para `Data.Oracle` indicada en la fase 3. Publicar los paquetes de producción con la versión **10.0.0-rc1**. Este documento es un plan: no significa que la migración o las pruebas ya se hayan ejecutado.

Se eliminan los **targets explícitos** `net47`, `net472`, `net6.0` y `net8.0`. Como `netstandard2.0` es compatible con varias plataformas, NuGet todavía podría seleccionar ese asset en aplicaciones con frameworks anteriores; eso no equivale a prometer soporte, pruebas ni publicación de assets nativos para ellos. Documentar este cambio y la nueva matriz de soporte.

La unidad de trabajo incluye `Data.sln`, la migración de `Data (With Dependencies).sln` para desarrollo con Common y sus procesos relacionados. Common ya soporta .NET 10: primero se generará y publicará su paquete `10.0.0-rc1` en `nuget.aseinfo.net`, y después se actualizará la dependencia de Data a esa versión. No se deben incorporar automáticamente proyectos que ya no existen ni modificar el repositorio Common sin coordinar los cambios entre ambos repositorios.
